What this policy covers

This policy explains how Golden Arc tools ("the tool") handles data. The tool is a private application used only by the channel owner to upload and manage videos on the YouTube channel Golden Arc. It is not offered to the public.

Use of YouTube API Services

The tool uses YouTube API Services. YouTube's terms are in the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • With the owner's permission (OAuth), the tool uploads and edits videos, thumbnails, captions and playlists on the owner's own channel, and reads basic channel information to confirm the correct channel is used.
  • It reads the analytics of the owner's own channel, such as views and watch time.
  • It reads publicly available statistics (views, likes, comment counts, titles, publish dates) of this channel and of public channels in the same topic area.
  • It reads the text and like counts of public comments on such videos, to understand what viewers ask about. It does not store commenters' names or account details.

The tool does not access any other user's private data, does not use cookies or tracking, and does not sell data.

Where data goes

The OAuth token is stored only on the owner's own computer and is sent only to Google. Statistics, analytics and comment text are stored on the owner's computer and are sent to Anthropic (Claude API), which is used to analyse them and plan videos; see the Anthropic Privacy Policy. Anthropic may process this data in the United States.

Deleting data and revoking access

Tokens, statistics and comment text can be deleted at any time by deleting them from the owner's computer. Access granted to the tool can be revoked at any time on the Google security settings page.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may process technical data such as IP addresses to deliver the page; see the GitHub Privacy Statement.

Your rights (GDPR)

If you are in the EU, you have the right to access, correct or delete personal data about you, to object to its processing, and to complain to a data protection authority. To use these rights, write to the email address above.
